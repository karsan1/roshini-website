# Project instructions

## Design

- Do not introduce gradients, glassmorphism, decorative animation, or generic stock imagery.
- Use one primary accent color. Prefer whitespace and typography to borders and shadows.
- Keep spacing tokens consistent and use accessible semantic HTML.

## Content

- Never invent research findings, publication details, awards, collaborations, or dates.
- Never upgrade a manuscript's status. Distinguish current work from completed work.
- Keep scientific claims traceable to supplied source material.

## Engineering

- Prefer Astro components, TypeScript, and authored CSS custom properties.
- Keep client JavaScript minimal and do not add React without a concrete need.
- Run checks and the production build before committing.
- Preserve GitHub Pages-safe routing and asset paths.
